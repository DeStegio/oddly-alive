# Interaction Catalog

The master plan lists 110 ideas (INT-001 … INT-110). This file is the
prioritized backlog and the tracking sheet. Status values: `planned`,
`in_progress`, `implemented`, `verified`, `deferred`.

Every built interaction must state: trigger, preconditions, state changes,
visual result, sound, cooldown, cleanup, keyboard/touch alternative, test.
These are recorded in code next to the behavior definition
(`src/engine/behaviors/*.ts`) and summarized here.
